使用办法：

将 version.dll 和 alsign.sig 这两个文件放在 LBPE 所在的文件夹（默认在 “C:\KEY\リトルバスターズ！ＰＥ” 文件夹，这个文件夹在非 Windows 11 及以上的非日文系统可能显示乱码），并挂载 Disc 2 盘到光盘驱动器中（用iso文件做虚拟光驱就行），启动游戏就可以了。

对于非东京时区/日文系统的用户，可能会在最开始弹出至多 3 次“Janpan Only”的警告，直接点击取消就可以进入游戏。

对于 Windows 8 及以上的用户，如果补丁无法运行，可以尝试将兼容模式进行关闭，实测 Windows 11 不开兼容模式也能正常运行游戏。

对于非 Windows 11 及更高版本的非日文系统的用户，在使用转区工具时需要将游戏所在的乱码文件夹重命名为仅ASCII字符串的文件夹名（简单来说就是只有英文字母和数字），推荐命名“C:\KEY\LBPE”。

Instructions for use:

Place the two files, version.dll and alsign.sig, in the folder where LBPE is located (by default, this is the folder "C:\KEY\リトルバスターズ！ＰＥ"; on non-Japanese systems that are not Windows 11 or later, this folder may appear as garbled text), and mount Disc 2 in your optical disc drive (using an ISO file as a virtual drive is fine). Then start the game.

For users in time zones other than Tokyo or on non-Japanese systems, up to 3 "Japan Only" warnings may pop up at the very beginning. You can simply click Cancel to enter the game.

For users on Windows 8 or later, if the patch does not run, you can try turning off compatibility mode. In practice, the game also runs normally on Windows 11 without enabling compatibility mode.

For users on non-Japanese systems that are not Windows 11 or later, when using a locale-switching tool, you need to rename the garbled folder containing the game to a folder name consisting only of ASCII characters (in simple terms, only English letters and numbers). Naming it "C:\KEY\LBPE" is recommended.
